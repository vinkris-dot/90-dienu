# 90 dienų

Mobili programėlė: 90 dienų be pridėtinio cukraus, baltų kvietinių miltų ir mėsos.
Vanduo (2 l), ėjimas (30 min), svoris, vegetariškas meniu, 90 dienų tinklelis.

Vienas failas be priklausomybių — `index.html`. Įrašai saugomi tik naršyklėje
(`localStorage`), atsarginę kopiją galima nusikopijuoti skiltyje „Kelias".

Adresas: https://vinkris-dot.github.io/90-dienu/
